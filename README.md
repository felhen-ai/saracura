# Saracura

[English](README.md) | [Português (Brasil)](docs/README.pt-BR.md)

Typed decisions over Brazilian Portuguese text: an open benchmark and small, fast decision models fine-tuned for PT-BR.

> Real Brazilian Portuguese. Open data. Measured on the same benchmark as everything else.

## What exists today

| Artifact | Where | What it is |
|---|---|---|
| **Benchmark** | [`felhen-ai/ptbr-typed-decisions-bench`](https://huggingface.co/datasets/felhen-ai/ptbr-typed-decisions-bench) | 7 typed-decision tasks over native PT-BR text from permissively licensed sources with human labels (legislative bills, court-of-accounts case law, scientific abstracts, social media comments, fact-checked claims, FAQ answers). Train, dev and test splits. |
| **Saracura PT-BR v0.1** | [`felhen-ai/saracura-ptbr-v0`](https://huggingface.co/felhen-ai/saracura-ptbr-v0) | A 322M-parameter decision model fine-tuned from [Laya](https://github.com/NandhaKishorM/laya) multilingual. Choice and yes/no decisions in one forward pass, about 3 ms per decision on a GPU, usable on CPU. |

A larger checkpoint (4B parameters, built with the [Kev](https://github.com/jaredpalmer/kev) recipe) is in training and
will be published under the same name family.

## Use the model

```bash
pip install laya
```

```python
import laya

agent = laya.load("felhen-ai/saracura-ptbr-v0")

result = agent.predict(
    "Requer informações ao Ministro da Saúde sobre a distribuição de vacinas nos municípios do interior.",
    {
        "tema": {
            "type": "choice",
            "instructions": "Qual é o tema desta proposição legislativa?",
            "criteria": {"saude": "Saúde", "educacao": "Educação", "economia": "Economia"},
        }
    },
)
print(result["answers"]["tema"]["choice"])  # saude
```

No account, no server, no download beyond the weights. The model card lists the full results, training data and
limitations.

## Results (balanced accuracy, benchmark test split)

| Model | Mean over 7 tasks |
|---|---:|
| Majority class | 27.6% |
| `convaiinnovations/laya-multilingual` (zero-shot) | 39.2% |
| `telepatia-ai/laya-pt-es-typed` (fine-tuned on translated data) | 44.6% |
| TF-IDF + logistic regression, one classifier per task | 64.0% |
| `Qwen/Qwen3.8-27B` zero-shot, with class descriptions (previous benchmark version) | 66.2% |
| **Saracura PT-BR v0.1 (322M, single model)** | **68.5%** |

On questions and texts the model never saw (generated by an open-weight teacher), v0.1 agrees with the teacher 86.8%
of the time on real texts and 89.6% on synthetic texts of eight product use cases (email triage, ticket routing, lead
qualification, WhatsApp intent, financial documents, product reviews, moderation, agent supervision). Those are
agreement numbers, not accuracy against human labels.

## Evaluate your own model

The benchmark rows are plain JSONL in the Laya request format: `text`, `type` (`choice` or `noul`), `instructions`,
`criteria` and `gold`. `research/bench.py` evaluates any Laya-compatible checkpoint and the classical baselines:

```bash
uv sync --dev
uv run python research/bench.py baselines
uv run python research/bench.py eval --name mine --model your-org/your-checkpoint --device cpu
```

Report balanced accuracy with the option order shuffled per item, as the scripts do, so results stay comparable.

## How the models are trained

Everything is in [`research/`](research/README.md): building the benchmark from the sources, generating varied
questions with open-weight teachers, fine-tuning with the upstream Laya and Kev recipes, and the evaluation scripts.
Training data that is not redistributed (marketplace listings, internal documents) is declared in the model cards.

The direction and its reasons are recorded in [ADR 0005](docs/decisions/0005-open-base-benchmark-first.md). Earlier
ADRs and the `src/` and `benchmarks/` packages belong to the research runtime that preceded it; they remain as a typed
API and a historical record.
